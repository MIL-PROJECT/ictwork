# 업무 추천 공통 시험 입력

최신 main의 `AssistRecommendTest`와 `recommend-vectors.test.ts`가 같은 경로의 JSON을 참조하지만, main 스냅샷에는 해당 파일이 없어 서버 검사가 실패하고 화면 검사가 생략됐다. `recommend_vectors.json`에 15개 합성 사례를 추가해 두 구현을 같은 입력과 기대 순서로 검사한다.

빈 검색·짧은 검색·일치 없음, 업무별 일치, 유형 번호에 따른 동점 순서, 최대 세 건, 구체적인 일치의 우선순위, 전각 문자·대소문자, 접수 가능 부서, 구분된 공통 안내 단어, 사용 중지·기타·설명 없는 유형을 포함한다. 서버와 화면의 기존 추천 규칙을 검사하는 고정 입력이며, 실제 모델의 추천 품질이나 운영 성능을 측정하는 자료가 아니다.
