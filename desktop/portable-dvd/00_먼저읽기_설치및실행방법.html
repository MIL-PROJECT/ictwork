2026-11-09 배포 · Windows 10/11 64비트

OMNIS DVD 설치 및 실행 안내

DVD의 프로그램 폴더를 PC에 복사해서 사용하는 방식입니다.
Java·MySQL 실행 환경과 기존 데이터가 함께 들어 있습니다.

① OMNIS 폴더 복사 → ② 필수 런타임 확인 → ③ OMNIS.exe 실행

1. OMNIS 폴더를 PC로 복사하세요

  1. DVD 드라이브를 열어 OMNIS 폴더를 선택하고 Ctrl+C를 누릅니다.
  2. 파일 탐색기의 문서 폴더로 이동해 Ctrl+V를 누릅니다.
  3. 약 1.8GB의 파일 복사가 완전히 끝날 때까지 기다립니다.

복사 후 위치 예: 문서\OMNIS\OMNIS.exe

하위 폴더와 파일을 모두 유지하세요. resources·locales·DLL을 포함한 OMNIS 폴더 전체가 필요합니다. 같은 이름의 폴더가 있다면 실행 중인 OMNIS를 종료하고 새 위치로 복사하세요.

2. VC++ 런타임을 확인하세요

  1. DVD의 vc_redist.x64.exe를 실행합니다.
  2. 설치가 필요한 경우 사용 조건에 동의하고 설치를 누릅니다. 관리자 승인 창이 나오면 PC 관리자에게 승인을 받습니다.
  3. 이미 설치되어 있거나 더 최신 버전이 있다는 안내라면 창을 닫고 다음 단계로 갑니다. 재시작 안내가 나오면 먼저 재시작합니다.

Microsoft 서명이 확인된 오프라인 런타임 파일입니다. Java·MySQL·Node.js를 별도로 설치할 필요는 없습니다. 조직의 설치·실행 정책으로 막히면 PC 관리자에게 문의하세요.

3. PC에 복사한 OMNIS를 실행하세요

  1. PC의 문서 → OMNIS 폴더를 엽니다.
  2. OMNIS.exe를 더블클릭합니다.
  3. 처음에는 데이터 복원과 서버 시작 때문에 시간이 걸릴 수 있습니다. 중복 실행하거나 강제로 종료하지 말고 기다립니다.
  4. 로그인 화면이 나오면 기존 계정과 암호를 입력합니다.
포함 데이터의 시연 계정
아이디: bn1-co1-admin
암호: Local-Demo-Init!26

sysadmin과 QA 마스터는 기존 암호를 사용합니다. 암호를 모르면 운영 관리자에게 확인하세요.

이후에는 PC에 복사된 OMNIS.exe를 실행합니다. 필요하면 그 파일의 바로가기를 바탕화면에 만드세요. 복사 후에는 DVD를 빼도 됩니다.

4. 종료와 데이터 보관

OMNIS 창을 닫으면 종료됩니다. Java·MySQL이 정상 종료할 시간을 조금 기다려 주세요.

  • 새 PC/새 프로필에는 2026-11-09 배포본의 데이터가 첫 실행에 복원됩니다. 기존 Final 프로필이 있다면 그 데이터를 이어서 사용합니다.
  • 사용자 데이터: %APPDATA%\OMNIS Desktop Final\service
    Final이라는 내부 경로는 기존 자료를 유지하기 위해 그대로 사용합니다.
  • 프로그램 폴더와 데이터 폴더는 별개입니다. 이후 입력한 자료는 DVD나 다른 PC로 자동 동기화되지 않습니다.
  • 백업은 정상 종료 후 service 폴더 전체를 복사합니다. 복원·PC 교체 시에는 대상 자료도 먼저 백업하고 운영 관리자와 진행하세요.
  • 로그인·상황판·업무 처리·관리자 기능·LOCAL AI는 인터넷 없이 사용할 수 있습니다. 외부 AI API·Ollama 모델은 별도로 구성해야 합니다.
  • 이전 SQLite 기반 OMNIS 데이터와 자동 이관하지 않습니다.

5. 실행되지 않을 때

  • DLL/필수 구성요소 오류: DVD의 vc_redist.x64.exe 설치 여부를 확인하세요.
  • 파일/폴더 오류: DVD의 OMNIS 폴더 전체를 PC의 새 위치로 다시 복사하세요.
  • 로그인 오류: 아이디·암호와 계정 잠금 여부를 운영 관리자에게 확인하세요.
  • 시작 실패: Win+R을 누르고 %APPDATA%\OMNIS Desktop Final\service를 입력합니다. spring.log·mysql.log·mysql-client.log·runtime-setup.log를 확인하거나 담당 관리자에게 필요한 부분을 전달하세요.
  • 보안 정책 차단: PC 관리자에게 실행 허용 여부를 확인하세요.

같은 안내를 메모장으로 보려면 텍스트 안내서를 여세요.

현재 PC의 기존 설치본 검증 및 이번 파일 복사 해시 대조를 완료했습니다. 다른 실제 PC와 물리 DVD의 호환성은 대상 환경에서 최종 확인해야 합니다. DVD 기록 담당자는 함께 있는 01_DVD에_굽는방법.txt를 참고하세요.
