OMNIS DVD — 설치 및 실행 방법
2026-11-09 배포 / Windows 10·11 64비트용

처음 사용한다면 ① OMNIS 폴더를 PC로 복사 → ② 필수 런타임 확인 → ③ OMNIS.exe 실행 순서로 진행하세요.
이 배포본은 프로그램 폴더를 복사해 사용하는 방식입니다. Java·MySQL은 포함되어 있습니다.

1. DVD에서 프로그램 폴더를 PC로 복사합니다

  (1) DVD 드라이브를 열어 OMNIS 폴더를 찾습니다.
  (2) OMNIS 폴더를 선택하고 Ctrl+C를 누릅니다.
  (3) 파일 탐색기의 문서 폴더로 이동한 다음 Ctrl+V를 누릅니다.
  (4) 약 1.8GB의 복사가 완전히 끝날 때까지 기다립니다.

  복사 후 실행 파일 위치 예: 문서\OMNIS\OMNIS.exe
  OMNIS 안의 resources, locales, DLL 등 모든 파일과 하위 폴더를 함께 유지하세요.
  같은 이름의 폴더가 있다면 실행 중인 OMNIS를 종료하고 새 위치에 복사하세요.
  복사 중 파일을 누락하거나 기존 실행 폴더를 무작정 덮어쓰지 마세요.

2. 필수 VC++ 런타임을 확인합니다

  (1) DVD의 vc_redist.x64.exe를 실행합니다.
  (2) 설치가 필요한 경우 사용 조건에 동의한 뒤 설치를 누릅니다.
  (3) 관리자 승인 창이 나오면 PC 관리자에게 승인을 받습니다.
  (4) 이미 설치되어 있거나 더 최신 버전이 있다는 안내라면 창을 닫고 다음 단계로 갑니다.
  (5) 재시작이 필요하다는 안내가 나오면 PC를 재시작한 뒤 진행합니다.

  이 파일은 Microsoft 서명이 확인된 Visual C++ x64 오프라인 설치 파일입니다.
  Java, MySQL, Node.js를 별도로 설치하거나 인터넷에 연결할 필요는 없습니다.
  조직 PC의 설치·실행 정책으로 막히면 해당 PC 관리자에게 문의하세요.

3. PC에 복사한 OMNIS를 실행합니다

  (1) 문서\OMNIS 폴더를 엽니다.
  (2) OMNIS.exe를 더블클릭합니다.
  (3) 첫 실행에는 기존 데이터 복원과 서버 시작 때문에 시간이 걸릴 수 있습니다.
      시작 화면이 바뀔 때까지 기다리고 중복 실행하거나 강제로 종료하지 마세요.
  (4) 로그인 화면이 나오면 기존 계정과 암호를 입력합니다.

  포함 데이터의 시연 계정
    아이디: bn1-co1-admin
    암호:   Local-Demo-Init!26

  sysadmin과 QA 마스터는 기존 암호를 사용합니다. 암호를 모르면 운영 관리자에게 확인하세요.
  자주 사용할 경우 PC에 복사된 OMNIS.exe의 바로가기를 바탕화면에 만들어 사용하세요.
  이후에는 PC의 OMNIS 폴더에서 실행하면 됩니다. 실행용 파일을 복사한 뒤에는 DVD를 빼도 됩니다.

4. 사용 후 종료합니다

  OMNIS 창을 닫아 종료합니다. Java·MySQL이 정상 종료할 시간을 조금 기다려 주세요.
  실행 중인 PC를 강제로 끄거나 사용자 DB 파일을 개별 삭제하지 마세요.

5. 데이터와 오프라인 사용

  - 처음 실행하는 새 PC/새 프로필에는 2026-11-09 배포본에 담긴 데이터가 복원됩니다.
  - 이미 같은 Windows 사용자 프로필에 Final 데이터가 있다면 기존 데이터를 이어서 사용합니다.
  - 사용자 데이터 저장 위치:
      %APPDATA%\OMNIS Desktop Final\service
  - 위 경로에 Final이 남아 있는 것은 기존 자료를 유지하기 위한 내부 경로입니다.
  - 프로그램 폴더와 데이터 폴더는 별개입니다. 이후 입력한 자료는 DVD나 다른 PC로 자동 동기화되지 않습니다.
  - 데이터 백업은 OMNIS를 정상 종료하고 Java·MySQL 종료를 기다린 후 service 폴더 전체를 복사합니다.
  - 데이터 복원/PC 교체는 대상의 기존 자료도 먼저 백업한 뒤 운영 관리자와 진행하세요.
  - 로그인·상황판·업무 처리·관리자 기능·LOCAL AI는 인터넷 없이 사용할 수 있습니다.
  - 외부 AI API나 Ollama 모델은 별도 설정과 필요한 연결/모델 환경이 있어야 합니다.
  - 이전 SQLite 기반 OMNIS 데이터와 자동 이관하지 않습니다.

6. 실행되지 않을 때

  - DLL/필수 구성요소 오류: DVD의 vc_redist.x64.exe 설치 여부를 확인합니다.
  - 폴더/파일 오류: DVD의 OMNIS 폴더 전체를 PC의 새 위치로 다시 복사합니다.
  - 로그인 오류: 아이디·암호와 계정 잠금 여부를 운영 관리자에게 확인합니다.
  - 시작 실패: Win+R을 누르고 아래 경로를 입력해 로그를 확인하거나 관리자에게 전달합니다.
      %APPDATA%\OMNIS Desktop Final\service
    로그 파일: spring.log, mysql.log, mysql-client.log, runtime-setup.log
    로그를 공개 게시판에 올리지 말고 담당 관리자에게 필요한 부분만 전달하세요.
  - 보안 정책 차단: PC 관리자에게 실행 허용 여부를 확인합니다.

배포 내용: OMNIS 프로그램 폴더, VC++ 런타임, 이 안내서, DVD 굽기 안내, 파일 체크섬.
동일 PC에서의 기존 설치본 검증 및 이번 파일 복사 해시 대조를 완료했습니다.
실제 다른 물리 PC와 DVD 기록/드라이브 호환성은 대상 환경에서 최종 확인해야 합니다.
