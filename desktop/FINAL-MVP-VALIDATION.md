## 검증 한계와 기존 사항

- 전체 프런트엔드 lint는 기존 오류 3개와 경고 14개로 성공하지 않는다. 오류 파일 CalendarEventModal.tsx·ThemeContext.tsx·svg.d.ts는 이번 통합에서 최신 main 대비 변경하지 않았다.
- 로컬 Ollama 127.0.0.1:11434가 응답하지 않았다. 실제 모델 추론·답변 품질·실운영 성능을 검증한 결과로 해석하지 않는다. AI 기본 비활성화와 로컬 실행기 설정은 최신 main의 동작을 유지한다.
- 현재 Windows PC의 폴더형 실행본을 검증했다. 다른 PC·새 Windows, 물리적 망 분리, 모든 화면의 수동 전체 CRUD 시험은 포함하지 않는다.
- 새 NSIS 설치 파일을 만들거나 기존 무인 재설치 대기 문제를 해결한 변경은 아니다. 해당 제한은 README에 유지한다.
