# AI 화면·메뉴·원본 AI 기능 보완 (2026-11-08)

## 소스 적용

대상은 `military_project_final`이다. 기존 개발 프로필은 유지했고 새 개발용 WAR로 재시작했다. Setup.exe 및 배포 resources는 갱신하지 않았다.

AI 질의응답은 실제 본문 시작 위치·하단 여백·계정의 글자 배율을 측정해 남은 높이를 사용한다. 대화 목록·본문·입력창을 flex/grid로 나누고 입력창은 고정한다. 긴 대화와 분석 결과만 패널 내부에서 스크롤한다. 대화 목록은 본문 폭이 좁아지면 접힌 목록과 겹침 패널로 전환한다. 큰 글씨·낮은 창에서는 장식과 반복 안내를 줄이고 이용 안내는 별도 펼침으로 제공한다. 안내·질문 예시·기존 대화·중지·출처·업무지원 연결은 유지한다.

메뉴 이름은 시스템 관리, 업무처리, 접수대기, 요청현황, 업무유형, 업무통계로 변경했다. 시스템 관리에는 관리 메뉴의 사람 아이콘과 구분되는 톱니바퀴 아이콘을 적용했다. SYS_ADMIN 역할과 기존 권한 판정은 유지한다.

## 원본 AI 검토와 반영

로컬 `military_project/src/renderer/src/AiManagement.tsx` 및 `src/main/ai/LocalRuleProvider.ts`, `AIProvider.ts`, `AppService.ts`의 실제 기능을 비교했다. 현 버전에는 일부 조회 기능만 채팅으로 연결돼 있어 AI 질의응답 안에 **업무 분석**을 추가했다.

| 원본 | 현재 버전의 적용 |
| --- | --- |
| 일일 운영 요약 | 현재 조회 가능한 체계·미완료·긴급·기한 경과·오늘 완료 집계 |
| 고장 분류·우선순위 | 입력 증상·서비스 영향에 대한 분류·우선순위·확인 사항 제안 |
| 정비 우선순위 | 실제 미완료 업무를 긴급 → 확정 종료기한 경과 → 예정·희망 종료일 순으로 최대 5건 제안 |
| 유사 고장 | 권한 안의 현재·과거 업무 제목의 표현 유사도로 최대 5건과 원문 링크 제공 |

이 네 가지 빠른 분석은 LOCAL 규칙으로 동작하며 외부 모델·키·과금이 필요 없다. 채팅의 Ollama / OpenAI / Anthropic 설정·연결은 기존대로 유지했다. 원본의 확률처럼 보이는 고정 신뢰도, 고정 팀 코드와 임의 소요시간·SLA 위험도는 현재 업무 모델에 검증된 근거가 없어 추가하지 않았다. 희망일을 확정 SLA로 취급하지 않는다. 모델 학습 기반 의미 유사도나 진단 결과라고 표시하지 않는다.

분석 API는 기존 업무·운영체계 조회 서비스와 현재 역할 범위를 사용한다. UI가 보낸 ID나 모델이 만든 수치로 집계하지 않는다. 분석 결과는 업무 데이터를 자동 변경하지 않는다. 실행 기능·규칙 버전·결과 수는 감사 기록에 남기고 입력 증상은 감사에 저장하지 않는다. API 인증·CSRF·길이 제한·AI 사용 중지와 프런트의 30초 제한/취소/지난 요청 결과 무효화를 적용했다. 분석 결과 자체의 별도 보관 화면은 기존 대화 이력·감사 기능과 중복돼 이번에는 추가하지 않았다.

## 검증

- TypeScript/Vite production build, 변경 TS/TSX ESLint, 개발용 WAR 및 테스트 컴파일 통과.
- 관련 백엔드 26개 테스트 통과: 신규 분석 API 4, 분류·정렬·유사도 규칙 3, 기존 LOCAL 규칙 3, 기존 채팅 B01 8, 운영현황 8. 전체 백엔드 테스트를 이번 변경 뒤 다시 모두 실행한 결과는 아니다.
- 복제 MySQL에서 기존 가입·관리자·채팅 실제 API 7그룹과 신규 분석 실제 API 4그룹 통과. 서로 다른 관리자/일반 사용자 범위에서 수치·결과 ID를 실제 목록과 대조했고, 인증·CSRF·잘못된 입력·민감 증상 감사 제외를 확인했다.
- 1366×768, 1280×720, 모바일 390×844, 큰 글씨 125% 1280×720에서 문서 세로/가로 넘침 없이 입력·보내기 표시와 빈 대화 표시를 확인했다. 1600×900 분석·채팅 화면, 125% 긴 응답의 패널 내부 스크롤, 다크 테마도 확인했다.
- 실제 dev 프로필에서 새 분석을 실행해 부서 관리자에게 미완료 132·긴급 15·기한 경과 43건이 표시됨을 확인했다. 별도 SYS_ADMIN 검증 프로필은 미완료 489·긴급 61·기한 경과 178건으로, 조회 범위 차이가 반영됐다. 시연 자료의 검증 시점 수치다.
- dev가 실행한 WAR 사본과 최종 빌드의 SHA-256이 같고, API 검증 사본의 AiAnalysisService 클래스도 최종 WAR와 같음을 확인했다. 개발 실행기는 WAR 사본을 열어 이후 소스 재빌드가 실행 중 아카이브를 덮어쓰지 않게 했다.
