# OMNIS 소스 UI 최종 확인

이 문서는 2026-11-08부터 이어진 관리자·AI·통합상황판·개인설정·장비 목록 소스 작업을 정리한다. Setup.exe와 설치된 사용자 DB에는 이번 UI 변경을 적용하지 않았다.

## 최종 UI

- 통합상황판: 통제 현황 카드 최대 6개, 등록된 경계 색상 기준 빨강 우선. 같은 지표는 최고 경계 상태를 대표로 표시하고 전체 부서 목록은 전체 지표에서 확인한다. GPS 전파교란은 비정상/정상으로 표시한다.
- 운영현황·접수대기·지시사항은 페이지당 최대 4개이며 마지막 페이지는 남은 항목만 표시한다. 지시사항은 명의자(직책·이름), 내용, 일시 열로 구성한다. 하단 목록 행이 페이지 영역까지 채워진다.
- AI 업무 분석 버튼은 기본 52px/낮은 화면 44px, 아이콘 24px이다. 개인설정은 표시·달력 설정을 한 카드에 배치하고 작은 화면에서는 그룹 전환을 사용한다.
- 사용자 메뉴의 개인설정·언어·로그아웃 아이콘 시작 위치를 통일했다. 언어 목록은 메뉴 안에 펼쳐져 사이드바에 잘리지 않는다. 접힌 사이드바의 로고 중앙과 사이드바 중앙의 차이는 0px이다.
- 장비 목록에서 배정된 업무 열과 열 선택 항목을 제거했다. 기존 브라우저에 저장된 해당 열·정렬 설정도 유효한 열만 읽도록 기존 필터를 통해 제외된다. 배정 업무 데이터와 장비 상세의 업무 링크는 유지한다.
- 장비 조회 목록은 한 줄 요약과 40px 행 높이를 사용한다. 긴 내용은 말줄임하고 툴팁으로 전체 값을 제공한다. 편집 모드의 입력·오류 안내는 기존 동작을 유지한다.

## 이번 마무리 검증

- 프런트엔드 Node 테스트 111개 통과. 시스템 메뉴의 ADMIN_SYSTEM 접근 조건을 테스트에 반영했다.
- 데스크톱 schema bridge·최종 DB bootstrap·DB merge 테스트 13개 통과.
- 열 설정 호환 검사 4개 통과: 제거된 열 제외, 다른 열·추가 특성 보존, 제거된 열만 저장된 경우 기본 열 복원, 손상된 JSON 기본값 복원.
- 변경된 프런트엔드 TypeScript/TSX 34개 파일 ESLint, TypeScript/Vite production build, Git whitespace 검사 통과.
- 실제 dev 화면의 장비 20행이 모두 40px임을 측정했다. 배정 업무 열이 목록 및 열 선택에서 사라지고, 야전 발전기 상세에서는 기존 배정 업무 링크가 표시됨을 확인했다.
- 한국어 → 영어 → 새로고침 후 영어 유지 → 한국어 복원을 확인했다. 사용자 메뉴 아이콘 세 개의 시작 위치가 같고 개인설정 페이지 이동도 확인했다.
