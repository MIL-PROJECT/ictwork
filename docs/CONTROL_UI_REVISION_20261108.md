# 통제 현황 및 카드 UI 수정 (2026-11-08)

이번 변경은 프런트엔드 소스에 적용했다. 설치 프로그램과 배포 패키지는 갱신하지 않았다.

## 변경

- AI 업무 분석 버튼: 기본 높이 52px, 낮은 화면 44px, 아이콘 24px.
- 통제·주의 구역을 통제 현황 카드 한 곳으로 통합하고 상단 빨간색 강조선을 제거했다.
- 같은 지표 이름은 등록된 색상의 경계 순위가 가장 높은 부서의 상태로 대표한다. CPCON·위기경보단계·GPS 전파교란을 포함하고 남는 자리에 높은 경계 지표를 채워 최대 6개를 표시한다. 표시 순서는 빨강 → 주황 → 노랑 → 파랑 → 초록 → 회색이다. 동률은 수정 시각, ID 순서다. 전체 부서별 목록은 기존 전체 지표 보기에서 확인한다.
- GPS 전파교란의 기존 대표 내용 `있음/없음`을 카드·전체 지표·상세에서 `비정상/정상`으로 표시한다. 저장 값, 편집 양식, 사용자 지정 내용과 경계 색상은 변경하지 않는다.
- 운영현황 카드의 왼쪽 색상 띠를 카드와 같은 20px 모서리 안에서 자른다. 메뉴가 표시되는 바깥 영역은 유지했다.
- QA 박스에 QA 모드와 계정 바꾸기를 한 줄로 표시한다. 주황색과 AI 상태 박스와 동일한 기본 높이를 유지한다.
- 운영현황 표는 한 페이지 4행을 유지한다. 표·업무 진행·접수 대기·지시사항의 마지막 행이 페이지 영역까지 채워지도록 행 높이를 배분한다. 실제 항목이 적은 페이지에 가짜 행은 추가하지 않는다.

## 검증

- `node --experimental-strip-types --test scripts/board-state.test.ts`: 14개 통과. 대표 지표 선정, 경계 정렬, 중복·숨김 처리, 원본 불변성, GPS 표시 변환 포함.
- 변경된 TypeScript/TSX 8개 파일 ESLint 통과, `pnpm build` 통과, `git diff --check` 통과.
- 실제 dev 화면에서 표의 두 번째 페이지 5–8/38개 표시, 전체 지표와 GPS 상세 이동, 카드 메뉴, QA 계정 전환을 확인했다.
- 1920×1080: 통제 카드 6개, 빨강 우선, 각 목록의 마지막 행과 페이지 영역 간격 0px. QA·AI 상태 박스 높이 각각 41.25px.
- AI 분석 화면 1366×768, 1366×660, 390×844에서 페이지 바깥 스크롤 없이 입력·실행 영역 표시를 확인했다. 로컬 일일 요약 API 응답도 화면에 표시했다.
- 검증용 QA는 별도 로컬 DB에서 수행했다. 백엔드·외부 AI 공급자·설치 프로그램 전체 재검증은 이번 프런트엔드 변경 범위에 포함하지 않았다.
